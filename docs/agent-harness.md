# 阅读 Agent Harness

## 请求流程

`ReadingRequest` 保留项目、文档、请求与会话 ID，动作、问题、选区与页码锚点、显式历史、语言和联网策略。应用校验作用域，冻结选区，先检查语义与版本兼容的缓存，再将最小原文证据交给主模型。简单解释一次模型调用即可完成；需要检索时同一逻辑 Agent 进入有界工具循环。

普通阅读仅开放当前书、项目检索和允许的网络工具。笔记、脑图等工具只在用户任务需要时开放。支持 OpenAI function calls 的模型使用原生协议；其他模型使用受校验的 JSON plan，最终回答仍为 Markdown。每个原生 call 都有对应 result，超额工具显式拒绝。

## 证据与回答

证据以稳定 ID 连接文档／页码／分块或网页 URL，附摘录、类型、抓取时间和内容哈希。选区只证明选中的局部文字，不能证明整页或全书缺失信息。查询去除多余任务话术并限制长度；无关候选不能作为引用依据，必要时读取候选正文。

同源追踪参数规范化，转载来源保留身份并归为重复组，不算独立佐证。确定性词项覆盖与数字差异只提供候选缺口／冲突信号，不代表语义核验结论。主模型按定义、时间、条件和方法处理差异，无法核实时保留具体缺口。上下文优先保留问题、完整选区和冲突证据，再压缩其他摘录与完整工具交换，不上传全书。

Prompt 独立记录基础约束、证据策略、任务模板和回答契约版本。词汇默认单句定义；用户补充问题优先，深度理解先给结论。不输出来源口播或模板化套话，必要否定与不确定性保留。所有出口校验引用；精确注册别名转换为稳定 ID，不对近似 ID 猜配。无效引用至多一次有预算修复，仍违规则不写完整复用缓存，不使用无限 repair 或正文删句。

## MCP 边界

应用使用官方 SDK 启动固定的本地 stdio server，发现 `search_web`、`read_web_page` 并复用连接。模型供应商不需要支持 MCP。子进程只获得必要 PATH 和搜索设置，不继承模型密钥；诊断不进入 stdout 协议流。握手、工具调用、取消和应用退出均有界，后续请求可重新连接。

只有显式配置的 SearXNG 后端可访问本地地址。网页读取单独校验协议、凭据、DNS 全部地址和每次跳转，固定到已校验地址，拒绝私网、回环、metadata 和非 HTTP(S)。正文有大小与时间限制，不执行网页脚本或加载图片。不支持任意命令、通用 MCP 安装或远程 MCP 配置。

`tsx` 是 server 运行依赖，用于源代码与编译后 stdio 入口中的模块解析，不是用户可配置的执行器。

## 预算与恢复

所有模型尝试共用 `RunBudget`，统一绝对 deadline、输入与输出预留、重试及工具额度。主调用、可选冲突判断、最终综合和引用修复都计入；缺少 usage 的调用标为估算。工具 schema、显式历史、证据和系统提示均纳入输入窗口。

数据库存储请求、来源、运行状态、工具结果与使用量，不记录模型私有推理。重复 request ID 不重复生成，研究 run 不并发重放。创建／追加笔记在同一数据库事务记录 operation ID；终态 run 不重执行。中断后已提交产物保留，未完成任务显式失败；小幅追加自动，大幅改写和删除须用户确认。文件系统与数据库不是跨资源原子事务，异常文件应以数据库已提交版本核对，不自动重放写操作。

## 缓存与产物

schema v3 增量加入词汇变体，不覆盖旧缓存与稳定链接。兼容性包含语境、任务／Prompt 版本、问题、动作、历史及联网策略。未知语境采用保守指纹；语义识别不是通用词义消歧模型。网页新鲜度与保留期限分开，过期正文可删除但 URL、标题和历史引用保留。

消息与运行引用存 SQLite；原始书籍／分块、网页缓存可按来源查找。用户产物位于项目 `artifacts/notes`、`artifacts/mindmaps`，内部运行事件位于 `agent-runs`。基础摘要只使用书籍，引用 registry 存摘要 `structure_json`，不会自动合入问答或网络研究。

回退前保留升级备份与新数据，不以旧备份直接覆盖现有库。配置、密钥、用户 PDF、数据库、测试与报告沿用 `.gitignore`，不随公开仓库发布。
