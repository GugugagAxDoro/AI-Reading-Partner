# 验收与测试矩阵

本文是规划中的测试契约，当前所有 case 均为**待实现/待运行**，不是已通过的报告。规范中的 WHEN/THEN 场景是基础契约，本矩阵补充执行步骤、观察点、冒烟选择和持久化验证。实现时参数化展开错误类型、终止路径和展示表面，不能用一次 happy path 代替所有变体。

## 1. 环境与数据

- 每次执行使用独立临时 application data root、SQLite 和专用浏览器上下文，不读写用户真实书库；复用 `test-assets` 中合适中文短书或生成合成 PDF，不下载/上传用户大书。
- 书 A《量化阅读样本》4 页：第一页解释基准 Alpha，第二页讨论不同胜率，第三页包含正文引用的早期定义，第四页留出不充分论证。
- 书 B《补充概念样本》3 页：风险模型 Alpha、互补条件及同名不同义 Beta。两书位于同一项目；另一个项目放置带唯一哨兵词的书 C，验证越权和检索泄露。
- 网络 fixtures：同义解释、互补例子、不同基准的冲突解释、相同转载、日期过期、无日期、空结果、低相关度、不可读页面、恶意网页指令和私网跳转。
- 离线层模拟模型行为和 SearXNG HTTP 返回，但集成测试启动真实打包 MCP server 并经过 stdio 协议，不仅 mock 一个业务方法就宣称 MCP 通过。
- 真实联调单独启用用户已配置的模型和 SearXNG；不显示密钥，不将配置值写入测试报告。无配置或外部故障记为未运行/外部依赖失败，不伪装通过。
- 截图、DB 快照、原始响应和真实模型产物放在被忽略的 `docs/testing/artifacts/agent-harness/`；源测试与 PDF 沿用现有忽略规则，不为本次规划修改 gitignore。

### 2.2 MCP 与安全（M）

| ID | 操作与前提 | 必须验证的结果 | 层级 |
| --- | --- | --- | --- |
| M01 | 启动固定 server、发现工具，执行搜索与可读网页读取 | stdio 协议链路完整；连接可复用；结果 schema、title/URL/time/type 有效 | 协议集成/真实 |
| M02 | 模型无 native tools，以合法/非法 JSON plan 提交 | 合法请求经 MCP 执行；非法参数被拒；权限/预算与 native 路线一致 | 集成 |
| M03 | 返回超量搜索、超长网页和仅 snippet 的结果 | 投影结构仍完整；模型只收有界摘录；未读网页不标成全文验证 | 单元/集成 |
| M04 | 本地 SearXNG 返回私网、localhost、metadata、unsafe scheme、重定向与 DNS 变化 | backend 仍可用；任意结果读取不能借用例外访问私网；恶意目标零访问 | 安全集成 |

### 2.3 Harness、预算与恢复（H）

| ID | 操作与前提 | 必须验证的结果 | 层级 |
| --- | --- | --- | --- |
| H01 | agent 不断重提等价 query，检索连续无新增覆盖 | 等价查询去重；连续两次无进展停止扩展；终态和缺口可见 | 单元/集成 |
| H02 | 模型一次提议 5 个 native tool calls，单轮只剩 3 个许可 | 3 个执行、2 个明确拒绝；所有 IDs 恰有一个结果；下一模型请求协议合法 | 集成 |
| H03 | 多轮工具观察超长，需要压缩，并在较晚结果加入关键冲突 | 不出现半截 JSON/孤立 tool messages；冲突双方保留；完整原始材料仍可按 ID 查找 | 单元/集成 |
| H04 | 分别在 MCP search/read、judge、synthesis、stream 阶段取消 | 全链路取消；迟到回调不继续/改终态；partial 可见但不进入复用缓存 | 参数化集成/E2E |
| H05 | 将轮次、模型/工具次数、累计 token、deadline 分别设置为接近耗尽 | 所有子调用共享预算；不重新获得完整超时；预留可用时有界结束，否则显式 timeout | 参数化集成 |
| H06 | 返回 planner/query/judge/synthesis 已知用量及缺失 usage | 总量覆盖全部调用，重试计入；缺失标 unknown/estimate，不默认为准确零值 | 单元/集成 |
| H07 | 长选区与历史超预算，随后测试独立问题和显式追问 | 必要选区不截断；仍超限则模型零调用；独立历史零轮、追问不超过配置上限且不跨 scope | 单元/集成 |
| H08 | 同 request 重复提交，在创建笔记后模拟进程重启并重试 | 模型/写入不重复；中断变为可恢复终态；既有笔记不被覆盖，run 保留身份 | 集成/E2E |

## 3. 冒烟集合

首轮执行 12 项：**R01、R04、R06、R07、M01、H02、H04、A01、A02、C01、U01、U03**。

- 离线冒烟使用固定返回，覆盖本地零搜索、需要联网才调 MCP、web-off、故障降级、协议完整性、取消、直接开头、缓存和引用持久化。
- M01 必须实际启动应用自有 stdio server，不要求外部引擎可达。R04 的外部后端在离线层可模拟，但必须经过 MCP 协议。
- 冒烟通过后，运行 42 项完整矩阵及其参数化变体；不得只汇报矩阵行数而忽略某个出口、错误类型或权限变体。
- 真实冒烟单独执行 R01、R04、M01、A01、A02、U01，至少 1 次读取真实结果正文；外部站点不可读需记录失败或替换有效目标，不能把 snippet 冒充全文通过。

## 4. 截图与本地数据验证

| 检查点 | 截图 | 持久化/请求断言 |
| --- | --- | --- |
| 本地 Alpha 解释 | 选区、直接首句、书本引用 | 一组用户/回答消息；版本与来源齐全；外部调用 0 |
| 混合来源回答 | 合并解释、两个来源图标、来源详情 | MCP step 实际存在；URL/书页与 displayed refs 一致；无重复独立来源膨胀 |
| 引用定位 | 点击前来源详情与点击后 PDF 目标页 | document/page/anchor 匹配；跨书后原会话 document ID 不变 |
| 缓存二次命中 | cache 状态、稳定文字标记 | 缓存内容不被改写；模型与外部计数无增量；新会话消息可按行为正常新增 |
| 失败与取消 | 独立网络状态或 cancelled partial | terminal state、warning metadata、缺口记录正确；复用缓存无新增 |
| 保存/刷新/导出 | 笔记 reading view、刷新后引用、脑图 | 新笔记/版本/refs 数量符合一次操作；基础 summary hash 不变；导出来源匹配 |

执行前后记录隔离 DB 的关键表行数、对应 request/message/cache/source/note/run ID 与状态、笔记/导出文件哈希。对截图对应操作给出结构化 before/after diff，而非只检查目录里“出现了文件”。持久化文本应与最终展示文本一致；取消/失败部分与完整结果分别校验。报告不可包含秘密、用户正文或不必要的机器路径。

## 5. 中文质量与成本评测

建立至少 24 条人工标注样本：本书充分 6 条、本地缺口/跨书 4 条、外部事实/时效性 4 条、重复/冲突 4 条、故障/不确定性 3 条、表达与格式边界 3 条。输入使用合成中文短书，不依赖英文论文作为主要语料。

每条标注：允许/必须/禁止的检索类型、必须覆盖的事实与条件、可接受引用、不可声称的内容、预期首句类型、允许的展开内容。评分检查：

- 必须联网用例实际检索，禁止联网/本地充分用例没有多余外部请求。
- 必要结论有相关来源支持；没有捏造引用、把 snippet 说成全文、把书意替换为百科定义。
- 同义解释不重复；冲突的定义/条件保留；不凭来源类别或新旧武断裁决。
- 词汇首句格式、深度解读直接开头、无意义套话缺失；必要否定和限制存在。
- 报告 model/tool calls、各调用 prompt/completion tokens（缺失注明）、首段可见时间、总耗时、cache 命中和停止原因。记录 p50/p95，不以某次网络延迟宣称稳定提速。

确定性红线（权限、假来源、错误终态、工具协议、预算逃逸、秘密泄露）必须全部通过。真实模型评测逐条复核；错搜/漏搜、无依据结论或直接开头不合格需修正后复测相关组，不能只靠另一个模型的一句评分宣告通过。样本不足以证明普遍正确，报告保留残余风险。

## 6. 完成判定

规划完成只要求文档齐全、能力/任务/用例对应一致及 OpenSpec strict validation 通过。功能实现完成另外要求：12 项离线冒烟、完整矩阵、现有仓库回归、typecheck/build、UI 截图与本地数据验证通过；真实模型/MCP/SearXNG 验证有单独可审计结论。未运行或外部依赖阻塞必须明确标出，不能等同通过。真实 API 调用会产生费用，报告记录实际用量但不泄露凭据。
