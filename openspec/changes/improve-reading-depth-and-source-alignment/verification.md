# 验收计划与测试用例

本文是本轮规划，所有用例均为待实现／待运行，不代表已经通过。不能沿用上一轮 163／54／24 的通过数作为本轮结果。

## 1. 数据、基线与证据

- 使用独立临时应用目录、SQLite、浏览器上下文和合成中文 PDF；不操作用户书库，不读写真实用户对话，不使用 OCR。
- 语料包含：EBITDA、Alpha、增长投资、高胜率、短普通词、非金融概念、原文错误／片面／过时、可信网页冲突、snippet 不完整、无网与故障。
- 跨页回归用合成页文本模拟 PDF 41–42 位于 26 起始章节；浏览器样本使用小 PDF 的相同关系另验导航，不需要用户大书。可用私有短摘录复现，但不加入公开产物。
- 混排样本含中文、`EBITDA`、`Alpha/Beta`、`EV/EBITDA`、`12.5%`、`(A+B)`、`−1`、`α`、英文连字 `fi/fl`、空格、跨 item 短词和跨行／跨页选区，并有重复文本以验证歧义处理。
- 保留旧提交 `9cd5fbe` 的输出与几何基线；完成前后均保存全套参数、来源、调用、状态和截图。测试资料、密钥、原始模型报告与截图沿用现有 Git 忽略规则。

## 4. 几何与持久化验证方法

- 对已知 PDF 字符 advance 建立页坐标基准，转换为 CSS 坐标；比较被选范围左右边界、目标行和标记范围。字形墨迹框、字体 ascent 留白与浏览器行框分别记录，不能直接拿行框高度假定字形顶部。
- 合成夹具横向累计端点误差、标记相对目标范围误差以不超过 2 CSS px 为初始阻断阈值；必须同时选对字符和行。不同字号的垂直指标用字体度量校验，并人工核对 screenshot，不用任意大容差放过错行。
- 额外运行能复现当前问题的代表性 PDF 文本片段，保存修复前后对应坐标／截图，不能只测原本就对齐的样本。不能复现时记录具体限制，不宣称根因已修复。
- 浏览器视口为 1440×900 和 1100×800，侧栏 420／300px。DPR 和 zoom 参数化运行，截图含 native selection、词汇点线、段落两类标记、重叠和引用 tooltip；不声称手机真机通过。
- 操作前后比较 messages、缓存、annotations／锚点、runs、notes、note_versions 的数量及必要文本字段；点击历史记录应新增零行、零模型／网络调用。
- 核对 PDF SHA、笔记文件、进度、总结正文、旧消息和旧来源元数据；仅允许预期派生位置／索引变更，记录 migration 备份与重复执行结果。新建回答／笔记按一次操作产生精确增量。

每条预先标注：必要概念／条件、可接受例子、禁止错误、允许／必须／禁止工具、可接受来源及位置、直接开头和用户语言要求。每条按正确性、解释完整性、相关性、来源支持、表达五维 0–2 评分；每维至少 1 且总分至少 8 才接受。算术错误、捏造、错误因果、遗漏改变结论的条件、无依据引用或权限违规一票阻断，不能以高平均分抵消。

同类调试最多三轮，仍失败需改变策略或报告阻断，不重复相同请求碰运气。修复某条之后复测同组与固定 24 条，最后一轮仍有阻断问题则质量验收不得勾选。记录逐请求 model/tool calls、prompt/completion/unknown/estimated tokens、完成状态、首段可见时间与总时长 p50／p95；明确计时方法，不把轮询采样冒充精确 TTFT。
