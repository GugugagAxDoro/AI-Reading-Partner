## 内容质量阻断

完整真实模型评测运行了固定 24 条加 6 条重复用例。历史基线后首次人工审核为 13/30；最新 `final-capacity` 的结构检查为 30/30，逐条人工语义复核仅 17/30 接受，质量门槛仍未通过。结构合法或引用 ID 存在不代表论断被证据支持。

最新阻断包括：把有利滑点无依据地限定为极少数限价单情形、业务增长与投资回报前提混同、Alpha 截距与随机残差混同、线性期望被错误加上独立性前提，以及扩展论断附上不支持它的引用。重复案例还出现“胜率只在公式第一项”而第二项也含胜率、忽略折现率变化、趋势必然同向等错误。不能通过堆叠更多金融纠错规则或反复调用直到偶然成功来宣布通过。

默认详细解释使用强模型，明确简答使用轻量模型；本地复制配置的轻量／强模型对比均保留，不改变用户配置。最新固定集开始于查询分词边界、协议历史清理、正文错误分类、候选扩展与剩余预算修复之前；这些代码收到定向回归，但不能把固定集称作最终代码的完整验收。保留先前失败，不用局部复测覆盖整组失败。

评测通过实际 MCP 连接受控搜索数据，部分正文为隔离缓存中明确标记的合成资料，不是真实互联网验证；关键网页正文未成功读取的用例不能宣称已完成独立核验。最新固定集耗时 p50 约 19.708s、p95 约 94.797s，非精确首 token 延迟。

## 外部搜索阻断

本地 SearXNG 容器已启动。原搜狗适配器因 `resp.next_request` 异常崩溃；本地配置移除该引擎，Bing 改为区域入口 cn.bing.com，百度仍可能验证码。短中文查询能返回真实相关结果，但英语缩写／多词查询仍常返回法律软件、人物、汽车等同名内容。HTTP 200 与有候选都不能等同正确核验。

对同一网址对照主进程、精简环境子进程与实际 MCP：百度页面均返回 HTTP 403；东方财富同名词条正文均可读约 1360 字；Investopedia 返回 HTTP 402。未发现环境变量／CA 信任差异，不修改 TLS 安全策略、不绕过访问限制。东方财富可读只能证明工具通路正常，正文口径仍需分析，不能按域名自动当权威。MCP 现保留安全的错误分类与 HTTP 状态，不传递任意错误内容或响应正文。

原先固定前三条候选恰好漏掉第四条可读页面；搜索工具现允许主 agent 在必要时扩大至最多六条，仍受去重、无进展停止和预算限制，不强制增加正常请求调用。真实联调还复现了检索后剩余预算不足但仍预留完整输出的问题，已经按实际可用额度收缩最终输出并禁止受限结果复用。

真实模型＋MCP＋SearXNG 的可信正文和冲突分析仍未验收；后续诊断单独抓到正文不能冒充模型回答已经消费正文。原始失败和修复后尝试分别保留，不修改用户密钥或生产超时。

最新 `adaptive-budget` 联调：真实联网请求约 70.833 秒完成，累计 22467 tokens，`budgetLimited=true`；没有因不足以预留完整输出而直接失败，也没有把未读取的网页冒充已完成核验。主 agent 没有采用可读的第四条同查询候选，而改用同名但无关的后续查询；故答案仍只有摘要，正文门槛失败。输出将逐期 CAPM 差值和统计截距分别列出，但仍有未限定口径的表述，不能仅因完成状态或格式合法判为语义通过。停止重复同配置抽样，不用偶然可读页面或某次成功替代整体验收。

### 实现与根因修复

- 原先模型搜索后反复改查同名机构，不读取已发现正文，消耗预算后失败。对于用户明确要求联网并核验正文的请求，在首次模型分析前读取相关候选；普通充分本地请求及禁网请求不增加外部调用。
- 正文失败后同查询只扩展一次至最多六条，最多自动尝试两个替代页面，优先未失败主机和检索相关性；每次网络操作仍计入工具、token 和时间预算。用户明确指定 URL 时不替换来源；修复预读按评分误选其他 URL 的回归。
- 验证码、空壳和不相关正文不进入已读证据；被拒内容不因扩搜重新进入。保留安全错误分类和 HTTP 状态，不关闭 TLS、不绕过访问限制。
- 注册实际读取页面的 ID 和正文，分别记录未读 URL、已读查询和必需正文缺口。读取正文不等于事实已证实；未完成必需正文不成为完整可复用回答。
- 固定引用概念的相关性过滤及候选词面评分只用于检索，不是可信度或语义支持评分。证据策略 v8 补充跨来源支持范围、差异保留、自拟例子与推导标识，不引入每问必经的评审模型。
